# DragonMine Transparent Single Elements Bundle

This bundle contains **transparent PNG HUD elements** split into **single assets**.
Each major HUD part includes:

- **clean** version = stripped of text / numbers / entries where possible
- **example** version = shows placement / sample text / sample values

## What is included

- Main left and right HUD panels
- Top nameplate
- Information/stat headers
- Basic info rows
- Information stat rows (with **multiplier area** on the right)
- Statistics rows
- Bottom stat box
- Plus button / multiplier field / label & value micro elements
- Navigation buttons and icons
- Overlay accents and scan ring
- Full reference image

## Notes

- All PNG files are intended for Minecraft HUD / overlay implementation.
- Transparent backgrounds were preserved.
- For the **stats area**, clean elements do **not** include numbers or filled entries.
- Example elements are included so you can see how labels / values / multipliers should be placed.
- The **multiplier slot** is included through the clean stat-row designs and `clean_multiplier_field.png`.

## Folder guide

- `01_panels/` main panel bodies
- `02_headers/` section headers / subheaders
- `03_basic_info_rows*/` Level / TPs / Form / Class row assets
- `04_information_stat_rows/` STR / SKP / RES / VIT / PUR / ENE / TPC stat rows
- `05_statistics_rows/` melee / strike / stamina / defense / health / ki dmg / max ki / power / gravity / TP multiplier rows
- `06_micro_elements/` plus button, multiplier field, labels, values, multipliers
- `07_nameplate*/` top player name / race plate
- `08_navigation_buttons*/` bottom menu buttons (clean/example)
- `09_icons*/` icon assets
- `10_overlays*/` divider, scan ring, accent overlays

Folders ending with `_v3` contain alternate / more granular versions from the earlier split pack.
