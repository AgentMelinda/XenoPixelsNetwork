- **Released:** 2026-09-08

## Highlights

- Adds optional Controlify gamepad support with Normal and BT3 radial modes, Xbox-style combat chords, analogue flight, ascend/descend controls, charged kicks, building compatibility, vanish inputs and technique radial entries.
- Adds direct DragonMineZ point commands and CustomNPC quest reward compatibility through `/xenopoints` and the scripting bridge.
- Adds operator cleanup for stuck DragonMineZ ki attacks globally or by radius.
- Repairs Multi-Form ki-wave mirroring, Zanzoken ring replacement/landing, charged attack ownership and title-screen packet safety.
- Recovers missing DMZ saga combat enemies after normal quest start and resummon, while preserving DMZ quest ownership, progress, party scaling, difficulty and transformation metadata.
- Adds `/xenodmz saga diagnose [player]` and `/xenodmz saga respawn [player]` for spawn diagnostics and manual recovery.

## Repository Cleanup

- Removes committed Kilo/AI editor state, root screenshots, duplicate image folders, zero-byte root logs and legacy root `META-INF` files.
- Keeps the source tree, wiki, documentation, workflows, examples, scripts and required 1.21.1 dependency jars.
- Updates repository links to `AgentMelinda/XenoPixelsNetwork`.
