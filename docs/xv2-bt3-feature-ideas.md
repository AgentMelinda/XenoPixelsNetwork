# Xenoverse 2 / BT3 features worth adding

Honest roadmap for XenoPixels. Prefer **dedicated keybinds**, real DMZ anims, and no fake libraries.

## Control philosophy (current)

| Move | How |
|------|-----|
| Combo / finisher | Attack mash |
| Vanish | Double-tap A/D (optional alt keybinds) |
| Chase | Double-tap W **only** (never dragon / Z-Burst) |
| Backstep | Double-tap S |
| Z-Burst | **V** mid-combo |
| Special strike | **C** mid-combo |
| Charge fist | Hold **R** |
| Charge kick | Hold **MMB** |
| Dragon dash | Hold **B** only — standalone, clears combo |

---

## High priority (best bang / fits existing combat)

1. **Guard / block & stamina break**  
   Hold a key to block; empty STM = short stun. XV2 stamina break feel.

2. **Super counter / vanish counter**  
   Window after getting hit: press vanish to flip behind and punish.

3. **Ultimate skill (hold key)**  
   One big form-linked move (KI cost, long CD). Wire to DMZ technique or custom packet.

4. **Rush chain (BT3)**  
   After a knockup, press chase/V to follow and continue the string in the air.

5. **Sonic sway / afterimage step**  
   Short i-frames + side step with afterimages (you already have trail FX).

6. **Ki blast cancel**  
   From combo, dedicated key fires a small blast and ends/cancels string (BT3 style).

---

## Medium priority

7. **Transformation impact**  
   Short pose + ring + light AOE when entering custom forms.

8. **Lock-on switch & soft lock**  
   Cycle targets; freelook soft-lock for combos (combo already freelook-friendly).

9. **Training dummy + damage meter**  
   Promote dojo STUB: spawn dummy, show combo damage total.

10. **Super Soul–style passives**  
    Equipable buffs via items/config (kick dmg+, fly speed, vanish CD-).

11. **Parallel quest lite**  
    Timed “defeat N / survive” with simple rewards.

12. **Beam struggle mini**  
    When two big attacks clash, mash QTE (if two players).

---

## Lower priority / polish

13. Emotes / victory poses (DMZ anim keys)  
14. Party shared CD strip  
15. Form fly aura while flying  
16. Cooldown HUD style presets  

---

## Explicitly keep separate

- **Dragon dash** = pure keybind (**B**), never from combo, never from double-tap W.  
- **Z-Burst** = **V** only, mid-combo.  
- **Chase** = double-tap W (or alt bind), not dragon.
