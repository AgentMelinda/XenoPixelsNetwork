What this needs that doesn't exist yet

Quests have no category. QuestDef is (id, title, desc, target, goal, reward) — no category field, so there is nothing to build tabs from. The world store already groups them (quests/<group>/<id>.json, QUESTS("quests", true)) so the folder can serve as the category — but datapack quests under npcs/quests/*.json are flat and would each need a "category".
No log text, and no completed text. There is only description, a one-liner. Paginating it would be paginating a single sentence. MyNPCs carries Text and CompleteText separately — both recorded in docs/xeno-npc-schema.md.
No completion NPC. Nothing records who a quest is turned in to; today a quest completes the instant its counter hits target. MyNPCs has CompleterNpc plus a QuestCompletion mode — "complete by NPC" versus player-manual. That is a behaviour change, not just a display field: it adds a hand-in step.
There is no player-facing faction screen to sit beside. client/npc/faction/ holds only ClientFactions, the sync mirror — factions are editor-only. So either that tab is MyNPCs' and ours ships alone for now, or a player faction screen is a second sub-project.
