# DragonMine Z — Other Menus Single Elements Pack

This bundle contains the **other redesigned menu assets** split into separate downloadable PNGs.

## What you asked for
You asked for:
- **the other elements**
- **the other menus redesigned**
- **split into single elements**
- **one example and one clean per element**
- **zipped for download**

This pack follows that structure as closely as possible from the generated UI asset sheets.

## Included menu groups
1. `server_menu/`
2. `skills_information/`
3. `quest_tree/`
4. `minigames/`
5. `options/`

Each menu group includes:
- `00_full_screens/` — full example + clean screen crops
- `01_panels/` — example + clean major panels
- `02_rows_buttons/` — rows, buttons, toggles, arrows, etc.
- `03_headers_accents/` — headers, dividers, icons, corner pieces, and accents

## Example vs Clean
- `example_*.png` = a filled version showing how the element should look with content
- `clean_*.png` = a blank/empty version meant for rendering content dynamically in code

## Notes
- These assets were cut from the generated menu sheets and organized into reusable pieces.
- In some cases there is only one natural clean or example version available from the source sheet.
- Full original asset sheets are also included in `00_original_asset_sheets/` for reference.
