# All Chat UI Elements — Clean Bundle

This ZIP groups together the **clean / no-text / reusable UI elements** created across this chat.

## What is included

### 1. `01_xenoverse_party_hud_clean/`
Clean Xenoverse-like party HUD assets:
- portrait rings
- HP / KI / STM clean bars
- ability icons
- badges
- arrows
- energy streaks
- empty frames / plates
- blank action button shells
- blank KI menu shells
- separate highlight overlay

### 2. `02_dragonmine_status_clean/`
Clean assets from the **DragonMine status / statistics redesign**:
- information panel
- statistics panel
- headers
- clean rows
- navigation buttons
- nameplate
- clean micro-elements
- overlays

### 3. `03_other_menus_clean/`
Clean and neutral assets from the **other redesigned menus**:
- server menu
- skills / information menu
- quest tree
- minigames
- options / settings

This folder keeps:
- `clean_*` assets
- neutral arrows
- icons
- dividers
- connector lines
- corner pieces
- scrollbars
- toggles
- nodes and other reusable parts

### 4. `04_legacy_clean_elements/`
Earlier single elements from the first DragonMine redesign pass.

## What was intentionally excluded
To keep this bundle focused on **clean assets**, I excluded:
- most `example_*` files
- full example mockup screens
- contact-sheet previews
- manifest JSON files
- original asset sheets that are mainly reference boards

## Notes
- Some elements in the conversation only existed as example-filled versions. Those were generally left out unless the asset was a neutral reusable piece.
- A few support assets like arrows, icons, and accent pieces are included even when they are not named `clean_*`, because they are still reusable clean elements.
- The old separate highlight for the menu row is included as an overlay.
