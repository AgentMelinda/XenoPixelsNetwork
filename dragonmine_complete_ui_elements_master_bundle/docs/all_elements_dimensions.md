This document lists the exported image elements included in the master bundle.

## Notes

- `clean` files are intended as implementation-ready transparent assets where available.
- `example` files show sample filled/textured versions when provided by the earlier bundles.
- `08_latest_generated_auto_split` was created by automatically splitting the latest full sheets into separate transparent components. Those elements use generic names like `element_001.png` because there was no authoritative per-part naming embedded in the sheets.
- `trimmed_bbox` is the non-transparent bounding box inside the stored canvas, formatted as `left,top,right,bottom`.
