# DragonMine / Xenoverse UI Master Bundle

This bundle combines the UI element packs created earlier in the chat together with the latest generated HD menu sheets.

## What is included

1. **Xenoverse Party HUD clean pack** extracted from the earlier transparent HUD bundle.
2. **Xenoverse Party HUD example pack** with text/example versions.
3. **DragonMine other menus clean + example pack** (server menu, skills info, quest tree, minigames, options).
4. **DragonMine status redesign v3** with clean/example rows, panels, icons, and overlays.
5. **DragonMine HD UI v4** with clean/example panels, rows, buttons, icons, and overlays.
6. **All-chat clean collection** from the earlier combined clean bundle.
7. **Latest generated full sheets** from the most recent redesign pass.
8. **Latest generated auto-split elements** where the newest full sheets were separated into individual transparent components.

## Folder guide

- `01_xenoverse_party_hud_clean/` - clean party HUD elements.
- `02_xenoverse_party_hud_example/` - example party HUD elements with labels/text.
- `03_dragonmine_other_menus_clean_and_example/` - earlier split clean/example assets for other menus.
- `04_dragonmine_status_redesign_v3/` - earlier status redesign assets.
- `05_dragonmine_hd_ui_v4/` - HD redesign elements from the later full-screen redesign.
- `06_all_chat_clean_collection/` - previous all-chat clean asset compilation.
- `07_latest_generated_full_sheets/` - newest full sheets kept intact.
- `08_latest_generated_auto_split/` - newest sheets split into separate PNG elements.
- `docs/` - dimension documentation and this README.

## Dimension documentation

- `docs/all_elements_dimensions.csv` - spreadsheet-friendly list of all image dimensions.
- `docs/all_elements_dimensions.md` - readable Markdown version.

## Important note

Some content appears in more than one source pack. This was intentionally preserved so you keep both the older exports and the latest reorganized versions in one place.
